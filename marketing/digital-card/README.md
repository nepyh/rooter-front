# Team Hyphen 디지털 명함 (루터)

휴대폰용 정적 사이트 (iOS·안드로이드). 빌드 없이 Vercel에 그대로 올려요.

## 정보 고치기 → 배포
1. `members.js` 고치기 (팀 소개, 앱 링크, 팀원 정보). 빈 칸("")은 화면에서 자동으로 빠져요. 전화번호만 `phones.js`에 따로 적어요 (GitHub 제외, 형식은 `phones.example.js`)
2. `./deploy.sh` 실행 → 연락처 파일(vcf/) 다시 만들고 Vercel에 배포
3. 처음 배포한 뒤엔 나온 주소를 `members.js`의 `siteUrl`에 적고 한 번 더 `./deploy.sh`

## 내 컴퓨터에서 보기
`./start.sh` → http://localhost:5180

## 기능
- 첫 화면: 팀 전체 명함 + 공유
- 팀원마다: 전화 · 문자 · 이메일 바로 연결, 연락처 저장(vcf/<id>.vcf, 루티 사진 포함), GitHub·인스타·블로그 링크
- 카드 눌러서 뒤집기 → 뒷면 QR = 그 사람 명함 페이지
- 개인 페이지(card.html?id=…): 카드 이미지 저장(폰은 공유 시트 → 사진에 저장), 공유
- 연락처 저장: 아이폰은 '새로운 연락처' 화면이 바로 뜸, 안드로이드는 내려받은 뒤 연락처 앱으로 열림
- 카카오톡 안에서 열면 '다른 브라우저로 열기' 안내 (카톡 브라우저는 연락처 저장이 막혀 있음)
